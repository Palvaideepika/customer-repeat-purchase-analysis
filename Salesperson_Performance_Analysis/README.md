# Salesperson Performance Analysis

## 📊 Project Overview

This project presents an interactive **Salesperson Performance Analysis Dashboard** created using **Microsoft Power BI** and the **Olist e-commerce dataset**.

The dashboard analyzes seller performance, sales, orders, customer reviews, seller locations, and sales trends to provide useful business insights.

## 🎯 Objectives

* Analyze overall sales performance
* Identify the top-performing sellers
* Analyze total orders
* Compare seller performance
* Analyze customer review ratings
* Identify top seller locations
* Monitor sales trends over time
* Provide interactive filtering by seller and order date

## 🗂️ Datasets Used

The project uses the following Olist datasets:

1. `olist_order_items_dataset.csv`
2. `olist_orders_dataset.csv`
3. `olist_order_reviews_dataset.csv`
4. `olist_sellers_dataset.csv`
5. `olist_customers_dataset.csv`

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query

## 📈 Dashboard Features

### KPI Cards

* **Total Sales**
* **Total Orders**
* **Average Order Value**

### Visualizations

* **Top 10 Sellers by Sales**
* **Top 10 Seller Locations by Sales**
* **Customer Review Ratings**
* **Sales Trend Over Time**

### Interactive Filters

* **Order Date**
* **Seller**

These filters allow users to analyze seller performance for specific time periods and individual sellers.

## 🔗 Data Model

The dashboard uses relationships between the Olist datasets to connect:

* Orders with order items
* Orders with customers
* Order items with sellers
* Orders with customer reviews

This enables integrated analysis across sales, sellers, customers, orders, and reviews.

## 🔍 Key Analysis Areas

### Seller Performance

Identifies sellers generating the highest sales and allows comparison of seller performance.

### Sales Analysis

Provides an overview of total sales and sales trends over time.

### Order Analysis

Measures the number of unique orders and helps understand order activity.

### Customer Satisfaction

Analyzes customer review scores from 1 to 5.

### Seller Location Analysis

Highlights seller locations associated with the highest sales.

## 📌 Project Outcome

An interactive Power BI dashboard was developed to provide a clear and user-friendly view of salesperson/seller performance.

The dashboard can help users identify high-performing sellers, understand customer satisfaction, monitor sales trends, and explore performance by seller and date.
